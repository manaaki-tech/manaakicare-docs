# Phone Calls and Emails

Manaaki Central groups all non-face-to-face contact under a single **Remote** <Term path="activity" /> type — not just phone calls and emails.

<Callout color="teal" title="Remote covers five contact types">
When you pick **Remote**, you'll choose a contact type: **Phone Call**, **Video Call**, **Email**, **SMS / Text**, or **Social Media**. All five use the same form.
</Callout>

## Recording a remote contact

Start a new <Term path="activity" /> the same way as any other — see [Recording Visits](/activities/recording-visits) for the full form walkthrough, including how the tabs and Save/Complete buttons work. The differences for Remote are all on the Essentials tab:

### Activity type

Click the **Remote** chip. This reveals a **Contact type** row instead of the Location field.

### Contact type

Choose one: Phone Call, Video Call, Email, SMS / Text, or Social Media.

### Everything else

Date & time, duration, priority, status (completed / didn't happen), and participants all work exactly as described in [Recording Visits](/activities/recording-visits) — a Remote <Term path="activity" /> doesn't require a location, but participants can still be added if relevant.

## Notes and follow-up

The Notes and Follow-up tabs are identical to every other <Term path="activity" /> type — see [Case Notes](/activities/case-notes) for writing up the contact and using templates.
