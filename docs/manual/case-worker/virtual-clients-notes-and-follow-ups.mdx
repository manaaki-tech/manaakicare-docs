# Notes, follow-ups and who looks after a virtual client

**By the end of this page** you will be able to write one note that covers
several people on a Police case, find notes again, resolve or cancel a
follow-up, and choose which case workers look after a virtual client.

A virtual client is a placeholder for someone named in a Police email. It holds
a date of birth, a gender and an address, never a name. The
[overview](/virtual-clients/overview) explains the idea. To put people on a
case first, see [registering a case and adding
people](/manual/case-worker/virtual-clients-register-and-add-people).

## Write one note for several people

You write a note once. The system saves a separate copy for each person you tag.

Start from the PO case page, in the **Notes** section. The note form opens
right there on the page, under the **Notes** heading. It is not a separate
window.

<Screen
  src="/img/manual/virtual-clients/notes-and-follow-ups/01-note-composer.png"
  alt="The New note panel with three people selected, a title box, the Essentials, Notes and Follow-up tabs, and Save note at the bottom"
  caption="Tick everyone the note is about. The footer tells you how many copies will be saved."
/>

1. Open the PO case page.
2. In the **Notes** section, press **Add note**.
3. Under **Who is this note about?**, select each person the note is about.
4. Type a title in the **Note title...** box.
5. Fill in the **Essentials** tab.
6. Open the **Notes** tab and write the note.
7. Press **Save note**.

You can also start from one person. Press the three dots (⋮) at the end of
their row in **People on this case**, then press **Add note for this person**.

Below the person chips, the footer shows **Select people above** until you pick
someone. After that it shows **Saved for n people**, with the number you picked.

After you press **Save note**, you see the message **Note saved for n people.**
Each person you tagged now has their own copy.

### What each person gets

- The note is stored as one copy per person. The composer says so: "Stored as n
  copies, one for each person."
- If you edit a note later, you change only one person's copy. The **Edit note**
  panel tells you which: "You are editing the copy for P1."
- You cannot add a note for a person whose involvement in that case is closed.

<Screen
  src="/img/manual/virtual-clients/notes-and-follow-ups/02-edit-one-copy.png"
  alt="The Edit note panel with a line saying which person's copy is being edited"
  caption="Editing changes one person's copy. Everyone else keeps theirs."
/>

Who may edit or delete a note:

- **Edit** — the person who wrote it, or a manager or supervisor.
- **Delete** — a manager or supervisor only.

### If a person is already in a care journey

Some people you tag may already have started a <Term path="serviceEpisode" />,
which the screen calls a care journey. Their copy goes on the care journey, not
on the PO case.

The composer warns you before you save:

- "Saved on the care journey for ..., not on this case"
- "... is in a care journey. New notes for them are saved there, not on this
  case."

For these people the form also asks you to say who was present at the visit.

When someone moves into a care journey, their earlier notes and follow-ups are
copied onto it too. Each copy keeps its PO number.

## Add a follow-up to a note

A follow-up is a reminder to do something by a date. You set it inside the note.

1. In the note panel, open the **Follow-up** tab.
2. Switch on **Follow-up required**.
3. Choose a date in **Follow-up Date**.
4. Press **Save note**.

The panel tells you what you have just asked for: "This creates a follow-up
for each person (n). Each one is closed separately."

The date must be between today and 6 months from now.

## Read and find notes

Notes for a PO case are in its **Notes** section. A virtual client's own page
also has a **Notes** section. It shows that person's notes across all their PO
cases, plus general notes.

1. Type in the **Search notes...** box to search the list.
2. Use the **By PO case** filter to show one case only. Each case in the list
   is marked **open** or closed.
3. Choose **General (no PO case)** in that filter to see notes that belong to no
   PO case.
4. Click a note in the list to read it.

The reading panel shows **Follow-up required** with the date when the note has
a follow-up. It also shows **Edit**, if you are allowed to use it.

## Add a note from the virtual client page

On a virtual client's page, a note is for that one person only. There is no
list of people to tag. Instead you say which PO case it belongs to.

1. Open the virtual client page.
2. In the **Notes** section, press **Add note**.
3. Under **Which PO case is this note for?**, choose the PO case.
4. Write the note and press **Save note**.

If the note does not belong to any case, choose **General (no PO case)**.

<Screen
  src="/img/manual/virtual-clients/notes-and-follow-ups/05-po-case-picker.png"
  alt="The picker asking which PO case a note is for, with two cases and a General option"
  caption="Choose the case the note belongs to, or General if it belongs to none."
/>

You cannot add a note for a person or link that is closed.

## Where your follow-ups show

- **Your dashboard** — the card **Virtual client follow-ups**. It lists the
  **Note**, the **Due Date** and the **Case / Client**. It shows only follow-ups
  assigned to you.
- **A PO case page** — the **Follow-ups** card.
- **A virtual client page** — the **Pending follow-ups** card.

With nothing due, the dashboard card says **No follow-ups due** and "Pending
follow-ups for the people you support will appear here." A PO case page says
"No follow-ups due."

Overdue follow-ups are marked.

## Resolve or cancel a follow-up

Use **Resolve** when the thing has been done. Use **Cancel** when it is no
longer needed. Either way, a closing note is required.

It works a little differently depending on where you are.

- **On your dashboard**, the **Virtual client follow-ups** card has **Resolve**
  and **Cancel** on each row.
- **On a PO case page**, the **Follow-ups** card has a tick box on each row, not
  a button. Tick the follow-up, then press **Resolve selected** or **Cancel
  selected** in the bar that appears. A **Resolve follow-up** window opens.

Then:

1. Press **Resolve** or **Cancel**, or tick the follow-up and press **Resolve
   selected** or **Cancel selected**.
2. Write the closing note.
3. Press **Resolve** (or **Cancel**) in the window to finish.

The closing note must say the right thing:

- For **Resolve**: "Add a closing note saying what was done."
- For **Cancel**: "Add a closing note saying why it is no longer needed."

Once it is done, you see **Follow-up resolved** or **Follow-up cancelled**.
The follow-up now carries a **Resolved** or **Cancelled** badge.

<Screen
  src="/img/manual/virtual-clients/notes-and-follow-ups/07-resolve-with-closing-note.png"
  alt="The Resolve follow-up window with a closing note typed in, opened from the Resolve selected bar on a PO case page"
  caption="On a PO case page you tick the follow-up first. A closing note is always required, for Resolve and for Cancel."
/>

### Close several at once

Use this when many follow-ups are finished together, on a PO case page.

1. Tick the follow-ups you want, or press **Select all**.
2. Check the count shown as "n selected".
3. Press **Resolve selected** or **Cancel selected**.

Press **Clear** to start again.

<Screen
  src="/img/manual/virtual-clients/notes-and-follow-ups/08-bulk-selection.png"
  alt="A follow-ups list with three selected and a bar offering Select all, Resolve selected, Cancel selected and Clear"
  caption="Pick several follow-ups, then resolve or cancel them together."
/>

Follow-ups can also be dealt with when you close a person's involvement in a
case. See [closing a person, and fixing
mistakes](/manual/case-worker/virtual-clients-closing-and-fixing).

## Assigned case workers

Each virtual client has a card called **Assigned case workers**. It shows which
staff look after this person.

1. Open the virtual client page.
2. On the **Assigned case workers** card, press **Manage**.
3. In the **Manage Case Workers** window, choose a person in **Select staff member**.
4. Press **Assign**.

A case worker can do this for a virtual client, as well as a manager. You do not
have to ask a manager first.

To take someone off, remove them in the same window. The system asks "Remove X
as ...?" before it does anything.

<Screen
  src="/img/manual/virtual-clients/notes-and-follow-ups/09-assigned-case-workers.png"
  alt="The Manage Case Workers window listing two assigned case workers with a Select staff member box and an Assign button"
  caption="Choose a staff member and press Assign. Removing someone asks you to confirm first."
/>

The rules:

- A virtual client has at most one active primary case worker.
- You cannot remove the last person assigned.
- You cannot assign anyone to a closed virtual client.
- Nobody is told. The system sends no notification when someone is assigned
  or taken off.
- Assigned case workers are not carried across when someone moves into a
  <Term path="serviceEpisode" />. Assign staff to the care journey in the
  normal way.

## If you see this message

| Message | What it means | What to do |
| --- | --- | --- |
| Start time is required | The note has no start time. | Enter a start time. |
| Start time cannot be in the future | The start time is later than now. | Enter a time that has already happened. |
| Note text is required | The note is empty. | Write the note in the **Notes** tab. |
| Follow-up date is required when follow-up is enabled | **Follow-up required** is on, but there is no date. | Choose a date, or switch the follow-up off. |
| Follow-up date must be between today and 6 months from now | The date is in the past or too far ahead. | Choose a date within the next 6 months. |
| Say who was present at the visit | A person you tagged is already in a care journey. | Say who was present. |
| Add a closing note saying what was done. | You pressed **Resolve** without a closing note. | Write what was done. |
| Add a closing note saying why it is no longer needed. | You pressed **Cancel** without a closing note. | Write why it is no longer needed. |

## If your screen does not match this page

- **You cannot see Virtual Clients in the left menu** — your service has not
  switched the feature on. Ask your administrator.
- **You cannot find Add note** — you may be on the list page. Open the PO case
  or the virtual client first.
- **There is no Delete on a note** — only a manager or a supervisor can delete
  notes.
- **There is no Edit on a note** — only the person who wrote it, or a manager
  or supervisor, can edit it.
- **A person is missing from the people you can tag** — they may not be on this
  PO case yet. See [registering a case and
  adding people](/manual/case-worker/virtual-clients-register-and-add-people).
- **Your dashboard shows no follow-ups** — it shows only those assigned to you.
  Look on the PO case page or the virtual client page to see the rest.
- **The same note appears twice in a list** — a note written for two people can
  appear as two rows in some lists. That is one copy for each person.
- **Anything else looks different** — note what you see and tell your manager
  or administrator.
