# Registering a Police case and adding people

**By the end of this page** you will have registered a Police case from an
email, added each person named in it, and know what to do with every kind of
search result.

## What a virtual client is

Some services receive Police emails about family-harm incidents. The email names
a **PO number** (one incident) and lists the people involved. Nobody in those
emails has agreed to work with the service yet, so the system does not hold a
name for them.

Instead, each person is recorded as a **virtual client**. It is a placeholder.
It holds only a date of birth, a gender and an address. **It never holds a
name.** The names stay in the Police email. Search your inbox for the PO number
to find them.

If a person later agrees to work with the service, their virtual client is
linked to their real record. Until then, you record what you do on the virtual
client. For the full picture, see the
[Virtual clients overview](/virtual-clients/overview).

<Callout color="teal" title="Can't see Virtual Clients in the left menu?">
This feature is switched on service by service. If you are not staff on a
service that uses it, the menu item is not there. See the last section of this
page.
</Callout>

## Before you start

Have the Police email open. You will copy from it:

- The **PO number**
- The **date** the email was received
- For each person: their **Police person number**, **role**, and any **date of
  birth**, **gender** and **address** the email gives

## Register a PO case

1. Click **Virtual Clients** in the left-hand menu.
2. Click **Register PO Case** at the top of the screen.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/01-virtual-clients-list.png"
  alt="The Virtual Clients list with the left-hand menu item and the Register PO Case button marked."
  caption="Start from the left menu, then press Register PO Case."
/>

The page is called **Register PO case**. It says: "Copy the details from the
Police email, then add each person named in it."

If you are staff on more than one service that uses this feature, a **Service**
list appears first. Choose the service this case belongs to.

### Case details

3. In **PO number**, type the number from the email, for example PO123456.
4. Check **Source**. It starts on the Police source. If you choose **Other**, a
   box asks you to name the source.
5. In **Date received**, check the date. It starts on today. Change it if the
   email arrived earlier.
6. If the email gives it, fill in **Incident date**. This is optional.
7. If you know it, choose an **Incident type**. This is optional. If you choose
   **Other**, a box asks you to describe it.
8. Click **Done** to close the section.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/02-register-case-details.png"
  alt="The Case details section of the Register PO case page, with six numbered fields from PO number down to the Done button."
  caption="The fields marked with a star are required. Incident date and Incident type are optional."
/>

**Done** does not save anything. It folds the section into a short summary. Use
**Edit** on that summary to open it again.

The PO number must be new for your service. The check ignores capital letters,
so po123456 and PO123456 count as the same number.

### People on this case

Now add each person named in the email. Do this for one person at a time. The
steps are in [Adding a person](#adding-a-person) below.

You can register a case with nobody on it and add people later from the case
page. The checklist on the right calls the people step optional.

### Register the case

9. Look at the checklist on the right. It is headed **Before you register**, and
   changes to **Ready to register** when you can go ahead.
10. Click **Register case**.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/03-ready-to-register.png"
  alt="The Register PO case page with two people added and the checklist showing Ready to register."
  caption="Nothing is saved until you press Register case."
/>

The button is only available when there is a PO number and no half-finished
person. If a person is still being added, the checklist tells you to add them to
the case or clear them.

**Nothing is saved until you register.**

After you click, the button reads **Registering...**. Then a message says **PO
case registered** and the case page opens.

If one person could not be saved, you see "PO case registered, but" and that
person's Police number, "was not added. Add them from the case page." The case
itself is saved. Add that person again as described below.

### If the screen shows an error

| Message | What to do |
| --- | --- |
| Enter the PO number | Type the PO number from the email. |
| Choose the source | Pick a source. |
| Enter the date received | Fill in **Date received**. |
| Date received cannot be in the future | Use today or an earlier date. |
| Incident date cannot be in the future | Use today or an earlier date. |
| Date received must be on or after the incident date | Check both dates against the email. |
| Name the source, since Other is chosen | Type the source in the box that appeared. |
| Describe the incident type, since Other is chosen | Type a short description in the box that appeared. |

## Adding a person

You add a person in the same way in two places:

- On the **Register PO case** page, under **People on this case**.
- Later, on the case page. Open the case, then click **Add person**. The form
  there is headed "Add a person to PO..." and says "Search for an existing
  virtual client, or create a new one."

<Callout color="amber" title="Always search before you create">
The system has no merge for duplicate virtual clients. If you create one by
mistake, it stays. Search first, every time, even if you think the person is
new.
</Callout>

### Search

The first part is headed **Find someone already known to the service**.

1. Type in one or more of these: **Police person number or virtual client
   number**, **Address**, or **Date of birth**.
2. Choose a **Gender** if you want to narrow the search. It starts on **Any**.
3. Click **Search**.

The search needs at least 2 characters in the number box or the address box, or
a date of birth. Gender on its own is not enough. If you try, you see: "Add a
date of birth, a Police person number, or an address. Gender alone matches too
many people."

The search matches part of a number, and capital letters do not matter. You can
type only the last digits. For example, 00008 finds VC-2026-ORG-00008. A search
by date of birth or by address works too, and shows the same results and
messages.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/04-search-for-a-person.png"
  alt="The Find someone already known to the service form with five numbered fields and the Search button."
  caption="Fill in what the Police email gives you, then press Search."
/>

### Read the results

Results appear under the heading "n matches for ..." with the question "Is it
one of these people?" If nothing matches, you see "No matches for ...".

Each row has a button. Which button, and any message on the row, depends on the
person.

| Message on the row | What it means | What to do |
| --- | --- | --- |
| No message | An open virtual client who has not yet agreed to work with the service. | Click **Choose** if it is the right person. |
| Ongoing care journey. This PO# will be added to it. | The person has agreed to work with the service and their <Term path="serviceEpisode" /> is running. | Click **Choose**. The PO case is attached straight to their <Term path="serviceEpisode" />. New notes go there too. |
| Closed, not consented. You will be asked whether to activate them. | This virtual client was closed and the person never agreed to work with the service. | Click **Choose**, then answer the question that follows. See below. |
| Consented, care journey closed. Start a new virtual client. | The person agreed to work with the service, and their <Term path="serviceEpisode" /> has ended. | Click **Create new**. There is no **Choose** button. The new form opens with date of birth and gender already filled in. |

A virtual client whose <Term path="serviceEpisode" /> has closed is never
reopened. That is why the only choice is a new one.

The search only shows virtual clients on services you are staff on. It hides
virtual clients who have agreed to work with the service, except in the two
cases in the table above.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/05-search-results.png"
  alt="Search results for a PO number: five virtual clients with a Choose button each, two of them carrying the message Ongoing care journey, and the None of these link at the bottom."
  caption="Rows with no message are open virtual clients. Read any message under a row before you press anything."
/>

**If the row says "Closed, not consented"**, click **Choose**. A question
appears: **Activate for this PO case?** There are two answers:

- **Yes, reopen work for this person**
- **No, record it as history only**

You must choose one. If you do not, you see "Choose whether to activate this
person for the PO case."

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/06-activate-question.png"
  alt="The Activate for this PO case question with two answers: reopen work, or record as history only."
  caption="Choose one before you carry on."
/>

**If nothing is right**, click the link at the bottom: **None of these. Create a
new virtual client**. It only appears after you have searched.

### What you chose

After **Choose**, a card shows "VC-... chosen". After creating a new one, it
shows **New virtual client**. Either card has a **Change** button if you picked
the wrong one.

For a new virtual client, fill in what the email gives you:

- **Date of birth** — optional, if Police provided it.
- **Gender** — male, female, non-binary, other, prefer not to say. Leave it
  blank if unknown.

The system never asks for a name.

### Address, number and role

1. Under **Use address from:**, pick an address to copy, or choose **Enter
   address manually**. One click copies the address, and the fields stay
   editable.
2. Fill in the address fields: **Street address**, **Unit/flat/floor**,
   **Suburb**, **Town or city**, **Region**, postcode and country.
3. In **Police person number**, type the number from the email, for example P1
   or V2. This is optional. If you leave it blank, the system builds one from
   the role, the PO case number and the date of birth.
4. Under **Role on this case**, click one chip: **Perpetrator**, **Victim**,
   **Mutual Participant** or **Not stated**.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/07-address-number-and-role.png"
  alt="The address, Police person number and role section of the Add person form, with four numbered areas."
  caption="Role is required. Police person number is optional."
/>

The address is the one given in the Police report. The form says: "As given in
the Police report. Their other cases keep their own address."

**Role on this case** is required. If you skip it, you see "Choose this person's
role on the case."

### Add them to the case

On the **Register PO case** page, click **Add to case**. The person appears in a
list headed **People on this case · n**. Each row says either "Linked to VC-..."
or "Creates a new virtual client". It also shows a role chip, an edit icon and a
remove icon.

To add the next person, the heading changes to "Add the next person (search
first to avoid duplicates)". Repeat from the search.

On the case page, click **Add person to case**. It stays greyed out until you
have chosen or created a person. Under it a hint says: "Choose a person from the
results, or create a new one, to continue." Afterwards you see **Person added
successfully**.

<Screen
  src="/img/manual/virtual-clients/register-and-add-people/08-people-on-this-case.png"
  alt="The People on this case card of a PO case page, listing two people with their Police number, role and status."
  caption="You can add more people from here at any time."
/>

### Two rules to know

- The same person cannot be on the same PO case twice.
- A **Police person number** can be used only once on a case. If you type one
  that is already there, you see "Another person on this case already has this
  number".

### Fix a mistake on a person

On the case page, click the pencil beside the person. The **Edit person** window
opens. You can change the Police person number there. If you leave it empty,
you see "Enter the Police person number".

If you linked someone to the wrong virtual client, or need to close a person's
involvement, see
[Closing and fixing mistakes](/manual/case-worker/virtual-clients-closing-and-fixing).

## If your screen does not match this page

- **There is no Virtual Clients item in the left menu.** Your service does not
  use this feature. It is switched on service by service. Ask your
  administrator.
- **You are sent to an access-denied page.** You are not staff on a service that
  uses this feature. Ask your administrator.
- **There is no Service list.** That is normal if you work on only one service
  that uses this feature.
- **You see "A PO case with this number already exists".** Another case in your
  service already uses that PO number. Search the **PO Cases** tab to find it.
- **The person you expect is not in the search results.** The search only shows
  virtual clients on your own services. It also hides people who have agreed to
  work with the service, unless their care journey is running or has closed.
  Try the last digits of the number, or a date of birth.
- **Something else looks different.** Tell your administrator what you see. Do
  not guess which button to press.
