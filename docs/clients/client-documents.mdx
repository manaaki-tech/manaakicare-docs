# <Term path="serviceUser" /> Identity Documents

The **Documents** tab on a <Term path="serviceUser" />'s [details page](/clients/viewing-client-details) holds identity document files that follow the person across every <Term path="referral" /> — things like a driver's licence or passport scan — rather than documents tied to a single <Term path="referral" />.

<Callout color="amber" title="Not the same as the Overview tab's Identity Documents card">
The <Term path="serviceUser" /> Overview tab also has a card called **Identity Documents**, but it records identity *numbers* (like an NHI) as structured fields — it does not hold files. This page is about the **Documents** tab, which is where the actual scanned or photographed files are uploaded. See [Viewing Client Details](/clients/viewing-client-details) for the Overview tab version.
</Callout>

<Callout color="teal" title="Different from referral documents">
Documents uploaded here belong to the <Term path="serviceUser" /> and stay attached to them regardless of how many <Term path="referral" plural /> they have. Documents attached to a specific <Term path="referral" /> — most commonly a signed consent form — are uploaded from within that <Term path="referral" /> instead. See [Uploading Referral Documents](/referrals/uploading-documents).
</Callout>

## Document types

When uploading, you choose one of the following types:

- Driver licence
- Passport
- Birth certificate
- IRD letter
- NHI letter
- Other identity document

## Uploading a document

1. Open the <Term path="serviceUser" />'s **Documents** tab and click **Add**
2. In the panel that opens, drag a file onto the drop zone or click it to browse
3. Fill in the fields:

| Field | Notes |
|-------|-------|
| **Title** | Required. Pre-filled from the file name, but you can change it |
| **Document type** | Required — one of the six types above |
| **Sensitivity** | Defaults to **Restricted** for identity documents (higher than the default for <Term path="referral" /> documents). Can be changed to Normal or Very Restricted |
| **Description** | Optional |
| **Issue date** | Optional, defaults to today |
| **Note** | Optional |

4. Submit the panel to complete the upload

## Accepted file types

| Category | Formats |
|----------|---------|
| **Documents** | PDF, Word (`.doc`, `.docx`), Excel (`.xls`, `.xlsx`), PowerPoint (`.ppt`, `.pptx`) |
| **Text** | `.txt`, `.csv` |
| **Images** | `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`, `.svg` |

**Maximum file size: 10 MB per file.**

## Viewing and downloading

Each uploaded document is listed with its title, type badge, and upload date. Click the download icon to save a copy — there is no in-browser preview.

## Deleting a document

Click the delete icon and confirm. The document is removed from the <Term path="serviceUser" />'s record but is soft-deleted rather than destroyed — it remains available in the audit log.
