# Searching for <Term path="serviceUser" plural />

The **Clients** page lists the <Term path="serviceUser" plural /> you work with, and gives you a single search box to narrow it down.

<Callout color="teal" title="Who you see here">
Administrators see everyone in the organisation. Supervisors, managers and intake officers see the people in the services they work in. <Term path="caseWorker" plural /> see the people assigned to them. The person search in **New Entry** looks across the whole organisation.
</Callout>

## Opening the list

Select **Clients** in the sidebar. The page loads with the <Term path="serviceUser" plural /> you can see, most recently added first, ten to a page.

## Searching

Type into the **Search clients...** box at the top of the page. Results filter automatically a moment after you stop typing — there is no need to press Enter.

The search matches:

- First name
- Last name
- Alias
- Reference number (the **ID** column)
- External reference (the **External Ref** column)
- Email address
- Phone number
- Whānau name

<Callout color="amber" title="Dates of birth do not match">
The search box does not match a <Term path="serviceUser" />'s date of birth, even though their age appears in the results. Search by name or reference number instead.
</Callout>

## Results table

| Column | Shows |
|--------|-------|
| (no heading) | A red warning icon if the person has a safety alert |
| **ID** | The <Term path="serviceUser" />'s reference number |
| **Name** | First and last name |
| **Alias** | An alternative name on file, if any |
| **Age** | Calculated from date of birth |
| **Whānau** | A link to the family group this person belongs to, if they're linked to one |
| **External Ref** | A reference number from an external system, if recorded |
| **Actions** | View profile and start a new entry |

Click anywhere on a row to open that <Term path="serviceUser" />'s [details page](/whanau/viewing-client-details). The **Actions** column offers the same view action plus a shortcut to start a new <Term path="referral" /> for that person, which takes you straight into the <Term path="referral" /> wizard with them pre-selected.

## Pagination

Results are paged 10, 20, or 50 at a time — choose a page size from the control at the bottom of the table. The footer shows how many records you're viewing (for example "Showing 1–10 of 47") and Previous/Next buttons to move between pages.

## Creating a new client from here

There is no **New Client** button on this page. New <Term path="serviceUser" plural /> are created from wherever they're needed:

- While [creating a Referral](/entries/creating-a-referral), if a search for the person turns up nothing
- From an existing <Term path="serviceUser" />'s [Whānau tab](/whanau/family-relationships), when adding a new family member who isn't already in the system

<Callout color="teal" title="Search before you create">
Both of those creation flows search first. If you're not sure whether someone is already in the system, try a couple of name spellings before creating a new record — duplicates fragment a person's history and are not simple to merge afterwards.
</Callout>
