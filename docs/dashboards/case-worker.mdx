# <Term path="caseWorker" /> <Term path="dashboard" />

The <Term path="caseWorker" /> <Term path="dashboard" /> — titled **"My <Term path="caseload" />"** — is your personal hub for managing assigned <Term path="serviceEpisode" plural /> and tracking <Term path="activity" plural /> that need follow-up. It gives you a focused view of your own workload.

## Overview

![Case Worker Dashboard Analytics](/img/dashboards/case-worker/analytics.png)

The dashboard displays:
- **Real-time metrics** showing your active <Term path="cases" />, urgent items, follow-ups, and <Term path="referral" /> counts
- **My Active <Term path="cases" />** table of all <Term path="serviceEpisode" plural /> assigned to you
- **<Term path="activity" plural /> Needing Follow-up** table of scheduled follow-ups sorted by date and priority

The dashboard description reads: *"View and manage your assigned <Term path="serviceEpisode" plural /> and <Term path="activity" plural />."*

## Analytics Section

The top section displays four metric cards summarising your current workload.

### Statistics Cards

| Card | Description |
|------|-------------|
| **Active <Term path="cases" />** | Number of active <Term path="serviceEpisode" plural /> assigned to you — the card reads *"<Term path="serviceEpisode" plural /> currently in progress"* |
| **Urgent/Crisis** | Combined count of urgent, crisis, and emergency priority <Term path="referral" plural /> |
| **Follow-ups Due** | Number of <Term path="activity" plural /> with scheduled follow-up dates |
| **Total <Term path="referral" plural />** | Total number of <Term path="referral" plural /> across all priority levels |

### Understanding the Numbers

- **Active <Term path="cases" />** reflects your current <Term path="serviceEpisode" /> assignments
- **Urgent/Crisis** sums up urgent + crisis + emergency priority <Term path="referral" plural /> — check these first
- **Follow-ups Due** counts <Term path="activity" plural /> where you have set a follow-up date that still needs action
- **Total <Term path="referral" plural />** shows your overall <Term path="referral" /> volume across all priorities (routine, priority, urgent, crisis, emergency)

## My Active <Term path="cases" /> {#my-active-cases}

![My Active Cases](/img/dashboards/case-worker/my-active-cases.png)

This section lists all <Term path="serviceEpisode" plural /> currently assigned to you.

The tile at the top of the page counts these as **Active <Term path="cases" />**, while the table itself is headed **My <Term path="serviceEpisode" plural />**. They are the same records under two names.

### Table Columns

| Column | Description |
|--------|-------------|
| **Reference** | The <Term path="serviceEpisode" /> reference number (e.g., SEP-2026-NPOWO-00015) |
| **<Term path="serviceUser" />** | Who the work is for, with their family underneath |
| **Service** | The service being delivered (displayed as a badge) |
| **Status** | Current status of the <Term path="serviceEpisode" /> |
| **Start Date** | When the <Term path="serviceEpisode" /> started |
| **Actions** | View button to open the <Term path="serviceEpisode" /> details |

### Status Badges

| Status | Meaning |
|--------|---------|
| **Awaiting Commencement** | <Term path="serviceEpisode" /> created but service delivery hasn't started yet |
| **Active** | Service delivery is in progress |
| **Completed** | Service delivery has been completed |
| **Closed** | <Term path="serviceEpisode" /> has been closed |

### Actions

- **View** — Click to open the full <Term path="serviceEpisode" /> detail page where you can manage the <Term path="serviceEpisode" />, record <Term path="activity" plural />, and view client information

### Sorting and columns

Most headings carry sort arrows — click one to order the table by it. **Columns**, above the table on the right, shows and hides individual columns.

### Pagination

Along the bottom of the table:

| Element | Description |
|---------|-------------|
| **Showing X–Y of Z** | Which records are currently displayed |
| **Rows** | How many to show per page — 10 by default |
| **Page X of Y** | Current page and total pages |
| **< >** arrows | Navigate between pages |

### Empty State

When you have no active <Term path="cases" />, you will see a green checkmark with the message: *"No active cases assigned to you."*

## <Term path="activity" plural /> Needing Follow-up {#activities-needing-follow-up}

![Activities Needing Follow-up](/img/dashboards/case-worker/activities-needing-follow-up.png)

This section shows all your <Term path="activity" plural /> that have a scheduled follow-up date, sorted by date and priority. It helps you stay on top of upcoming and overdue follow-ups.

### Table Columns

| Column | Description |
|--------|-------------|
| **Reference** | The <Term path="referral" /> reference number (e.g., REF-2026-NPOWO-00018) |
| **Title** | What the <Term path="activity" /> was called when it was recorded |
| **<Term path="serviceUser" />** | Who it concerns |
| **Service** | The service being delivered |
| **Follow-up Date** | The date you said you would come back to this |
| **Priority** | How urgent the <Term path="activity" /> is — shown as a badge |
| **Risk** | The risk level recorded against it |

Use **Columns** above the table to show or hide any of these.

<Callout color="amber" title="Sort by follow-up date first thing">
The follow-up date is the column that tells you what is late. Sort by it and work from the top — a date that has already passed is somebody you told you would ring back and did not.
</Callout>

### Actions

Click the **link icon** on any row to navigate directly to the <Term path="activity" /> detail page within its <Term path="serviceEpisode" />.

### Sorting and columns

The Title, <Term path="serviceUser" />, Service, Follow-up Date and Priority headings all sort. **Columns** shows and hides individual columns.

### Pagination

Same pattern as My Active <Term path="cases" /> — a rows-per-page selector and page navigation along the bottom.

### Empty State

When you have no follow-ups scheduled, you will see a green checkmark with the message: *"No follow-ups scheduled"*

## Common Tasks

### Finding something in a table

Sort by any heading with arrows beside it, and use **Columns** to hide the ones you do not need. Both tables paginate, so check the page count at the bottom before concluding something is missing.

### Refreshing data

Reload the page. The counts on the tiles are worked out when the page loads, so a number that looks stale usually is.

### Navigating to a <Term path="serviceEpisode" /> {#navigating-to-a-service-episode}

1. Find the <Term path="serviceEpisode" /> in the **My Active <Term path="cases" />** table
2. Click the **View** button
3. You will be taken to the full <Term path="serviceEpisode" /> page

### Navigating to an <Term path="activity" /> {#navigating-to-an-activity}

1. Find the <Term path="activity" /> in the **<Term path="activity" plural /> Needing Follow-up** table
2. Click the **link icon** in the Actions column
3. You will be taken to the <Term path="activity" /> detail page within its <Term path="serviceEpisode" />

## Tips for Efficient Work

### Daily Routine

1. **Start of Day**
   - Check the **Urgent/Crisis** card for high-priority items
   - Review **Follow-ups Due** for any overdue follow-ups (red badges)
   - Scan **My Active <Term path="cases" />** for <Term path="serviceEpisode" plural /> awaiting commencement

2. **Throughout the Day**
   - Record <Term path="activity" plural /> after each client interaction
   - Set follow-up dates on <Term path="activity" plural /> that need future action
   - Update <Term path="serviceEpisode" /> status as services progress

3. **End of Day**
   - Review upcoming follow-ups for tomorrow
   - Ensure all client interactions have been recorded
   - Check for any newly assigned <Term path="serviceEpisode" plural />

### Priority Management

| Priority | Expected Action |
|----------|----------------|
| **Overdue follow-ups** (red) | Address immediately |
| **Urgent/Crisis <Term path="referral" plural />** | Process same day |
| **Follow-ups due today or within 2 days** | Schedule into today's work |
| **Awaiting commencement <Term path="serviceEpisode" plural />** | Plan service start |
| **Routine follow-ups** | Process in order |

## Troubleshooting

### Dashboard Not Loading

1. Check your internet connection
2. Click the refresh button
3. Try logging out and back in
4. Clear your browser cache

### Missing <Term path="serviceEpisode" plural /> {#missing-service-episodes}

If you cannot find an assigned <Term path="serviceEpisode" />:
1. Check all pages using pagination
2. Use the search bar with the client name or reference number
3. The <Term path="serviceEpisode" /> may have been closed or reassigned — check with your supervisor

### Follow-up Dates Not Showing

<Term path="activity" plural /> only appear in the follow-up section if:
1. The <Term path="activity" /> has the **follow-up required** flag set
2. A **follow-up date** has been entered
3. The <Term path="activity" /> belongs to your assigned <Term path="serviceEpisode" plural />

### Data Not Updating

1. Click the refresh button
2. Wait a few moments and try again
3. Check if search filters are narrowing your view
4. Contact support if the issue persists
