# Navigating the System

Learn how to move around Manaaki Central efficiently using the navigation menu, search, and other navigation features.

## Overview

Manaaki Central uses a consistent navigation structure to help you find what you need quickly:

- **Sidebar Menu** — Main navigation to different sections
- **Header Bar** — The menu button, help, and the **New Entry** button
- **Search Bars** — Context-specific search within each section
- **Pagination** — Navigate through large lists of records

## Sidebar Menu

The left sidebar provides access to the main sections of Manaaki Central. It is always visible for quick navigation, and the currently active page is highlighted so you can see where you are at a glance.

| Menu Item | Path | Description |
|-----------|------|-------------|
| **Dashboard** | `/` | Your personalised dashboard based on your role |
| **Entries** | `/referrals` | The intake and <Term path="referral" /> entry point. Only intake staff, supervisors and managers see it |
| **In-progress Journeys** | `/care-journeys` | Active <Term path="serviceEpisode" plural /> currently in progress |
| **Completed Care** | `/completed-care` | <Term path="serviceEpisode" plural /> that have been completed or closed |

### The lower group

Beneath a divider sit three more items:

| Menu Item | Path | Who sees it |
|-----------|------|-------------|
| **Clients** | `/clients` | Everybody |
| **Organisations** | `/external-organisations` | Not everyone. It depends on your job |
| **Templates** | `/organisation-documents` | Everybody |

**Templates is not restricted.** It is easy to assume all three items are management-only because they sit together, but the document library is there for every role — if you can see Templates and not Organisations, nothing is wrong.

### Customised navigation labels

Navigation labels can be configured per organisation, so what you see may differ from the defaults above. Some organisations use te reo Māori phrases as their labels — for example, one organisation's set-up shows:

| Default label | Example label |
|---------------|-----------------|
| Clients | Whānau I am supporting |
| Completed Care | Preservation of Relationship |

If your sidebar looks different from a colleague's, this is expected — your organisation has configured its own terminology.

## Header Bar

The header bar at the top of every page contains:

| Element | Description |
|---------|-------------|
| **Menu button** | The panel icon at the far left. Hides or shows the sidebar |
| **Name bar** | Only when a <Term path="serviceEpisode" /> is open: the person's name, age and status. Click it to see more |
| **Help** | The **?** icon. Opens this manual |
| **New Entry** | Starts a new entry. Only intake staff, supervisors and managers see it |

Your name and organisation are at the bottom of the sidebar, above **Sign out**.

## Search

Each section includes a context-specific search bar to help you find records quickly.

### How to Search

1. Click in the search field
2. Type your search term (client name, reference number, referrer name)
3. On the **In-progress Journeys**, **Completed Care** and **Entries** lists, results appear after you have typed 3 letters and paused. To search for fewer letters, press **Enter**
4. Click on a result to open it

### Search Tips

- Client names give quick lookups across the Clients and Entries sections
- Reference numbers (e.g., `REF-2026-DEFAULT-00047`) provide exact matches
- Search works across multiple fields within each section

## Pagination

When viewing lists with many records, pagination controls appear at the bottom:

| Element | Description |
|---------|-------------|
| **Showing X–Y of Z** | Indicates which records are currently displayed |
| **Page X of Y** | Current page number and total pages |
| **< >** arrows | Navigate to previous/next page |

## Keyboard Shortcuts

Speed up navigation with keyboard shortcuts:

| Shortcut | Action |
|----------|--------|
| `Enter` | Submit search |
| `Esc` | Close dialogs or cancel actions |
